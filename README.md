# How's your Christmas

친구들이 크리스마스에 서로 편지를 쓸수록, 함께 쓰는 3D 미니어처 마을의 대왕 트리가 꾸며지는 웹 서비스입니다.

- 기획: `docs/prd.md` · 개발 순서: `docs/ROADMAP.md`
- 예전 시안·실험물: `_archive/` (실제 코드 아님)

## 내 컴퓨터에서 실행하기

```bash
npm install     # 처음 한 번: 필요한 도구 설치
npm run dev     # 개발 서버 켜기 → 브라우저에서 http://localhost:3000
```

비밀 값(Supabase·카카오·LINE 키)은 `.env.local`에 있으며 GitHub에 올리지 않습니다.
