# 앱에 직접 넣은 글꼴

Google Fonts에 없는 글꼴은 파일을 이 폴더에 두고 `app/layout.tsx`에서 `next/font/local`로 불러옵니다.

## 나눔스퀘어라운드 (NanumSquareRound) — 한국어 글꼴

- 파일: `NanumSquareRoundR.woff2`(보통, 400), `NanumSquareRoundB.woff2`(굵게, 700)
- 만든 곳: NAVER Corporation (디자인: 산돌커뮤니케이션). Copyright ⓒ 2017 NAVER Corporation.
- 사용 조건: SIL Open Font License 1.1 — 무료, 상업적 이용·웹 글꼴 사용 가능. 글꼴 파일만 따로 파는 것은 안 됩니다.
  안내: https://hangeul.naver.com/font
- 받은 곳: https://github.com/innks/NanumSquareRound (네이버 배포 글꼴을 웹용 woff2로 바꿔 둔 저장소, 2026-11-27에 받음)
- 한글 11,172자가 모두 들어 있습니다. 용량은 굵기 하나에 약 0.25MB이고, 한글이 화면에 나올 때만 내려받습니다.

일본어 글꼴(Zen Maru Gothic)은 Google Fonts에서 받으므로 여기에 파일이 없습니다.
