# 지인에게 보낼 안내 문구 (How's your Christmas)

> 첫 공개(12.3) 때 LINE·카카오톡으로 보낼 문구입니다. (Task 010, 11.27 작성)
> `<주소>` 자리에 운영 주소나 **내 마을의 초대 링크**를 넣어 보내세요.
> 초대 링크로 보내면 받는 사람이 로그인하자마자 내 마을에 바로 입주합니다.

## 쓰는 법

- **같은 마을에 부르고 싶을 때** → 마을 화면의 메뉴 → "초대"로 복사한 링크를 넣습니다. (추천)
- **서비스만 소개하고 싶을 때** → 운영 주소(`https://<운영주소>`)를 넣습니다. 받은 사람이 자기 마을을 새로 만듭니다.
- **한 마을의 정원은 30명입니다** (11.27 확정). 반이나 동아리처럼 큰 모임에 보낼 때는 "한 마을에 30명까지 들어올 수 있어"라고 함께 알려 주세요. 30명이 넘는 모임은 마을을 둘로 나눠 만듭니다. (31번째 사람은 "가득 찼어요" 안내와 함께 들어올 수 없습니다)
- **마을을 만들 때 정원(함께할 인원, 3~30명)을 정합니다** (11.28 확정). 트리는 "정원 전원이 서로에게 한 통씩" 쓰면 완성되므로, 실제로 모일 인원으로 정하라고 알려 주세요. 정원은 나중에 줄일 수 없고, 정원보다 많이 들어오면 자동으로 늘어납니다.
- 문구는 편하게 고쳐 쓰세요. 아래는 예시입니다.

## 한국어

### 짧은 버전 (대화방에 한 번에)

```
🎄 How's your Christmas
우리끼리 작은 눈 마을을 만들었어!
서로의 우체통에 편지를 넣으면 마을 트리에 장식이 하나씩 달려.
편지는 12월 25일에 다 같이 열어 보자 ✉️

들어오기 👉 <주소>
(LINE이나 카카오로 바로 시작할 수 있어)
```

### 조금 긴 버전 (처음 보는 사람에게)

```
🎄 How's your Christmas — 친구들과 편지를 주고받으며 마을 트리를 꾸미는 작은 서비스야.

어떻게 하냐면
1. 아래 링크로 들어와서 LINE이나 카카오로 시작하기
2. 마을에 내 집과 우체통이 생겨
3. 친구 집 앞 우체통까지 걸어가서 편지 쓰기
4. 편지가 모일수록 광장의 큰 트리에 장식이 늘어나

받은 편지는 크리스마스(12월 25일)까지 잠겨 있어서, 그날 다 같이 열어 보는 재미가 있어.
앱 설치 없이 휴대폰 브라우저에서 바로 돼.

👉 <주소>

아직 만드는 중이라 이상한 점이 있으면 편하게 알려 줘 🙏
```

### 다시 알릴 때 (며칠 뒤)

```
🎄 우리 마을 트리가 아직 덜 꾸며졌어!
편지 한 통만 더 써 주면 장식이 하나 더 달려 ✉️
👉 <주소>
```

## 日本語

### 短いバージョン（トークにそのまま）

```
🎄 How's your Christmas
みんなで小さな雪の村をつくったよ!
おたがいのポストに手紙を入れると、村のツリーに飾りがひとつずつ増えていくんだ。
手紙は12月25日にみんなで開けよう ✉️

ここから入ってね 👉 <주소>
(LINEかカカオですぐ始められるよ)
```

### 少し長いバージョン（はじめての人に）

```
🎄 How's your Christmas — 友だちと手紙を送り合って、村のツリーを飾る小さなサービスです。

遊び方
1. 下のリンクから入って、LINEかカカオではじめる
2. 村に自分の家とポストができる
3. 友だちの家の前のポストまで歩いて、手紙を書く
4. 手紙が集まるほど、広場の大きなツリーに飾りが増える

もらった手紙はクリスマス(12月25日)まで開けられないので、当日みんなで開けるのが楽しみになります。
アプリのインストールは不要で、スマホのブラウザでそのまま使えます。

👉 <주소>

まだ作っている途中なので、おかしなところがあったら気軽に教えてね 🙏
```

### もう一度知らせるとき（数日後）

```
🎄 村のツリー、まだ飾りが足りないよ!
手紙をもう1通書くと、飾りがひとつ増えるよ ✉️
👉 <주소>
```
